# SheetCalc.it app icon

The icon is a cream serif letter "S" with a red flower, a white flower and green leaves on a
navy rounded tile, supplied by Lorenzo D'Apolito for SheetCalc.it (first of the six variants).
It replaces the upstream GridCraft placeholder.

The PNG, `.ico` and `.icns` files here are generated from that artwork (rounded-corner alpha,
macOS body on Apple's 824/1024 grid). `gridcraft.svg` and the hicolor `scalable` SVG are still the
upstream placeholder and are not used by the desktop app.
